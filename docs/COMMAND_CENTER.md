# Адаптер JSON для Command Center

Приёмник: [Counter-UAS Sensor Fusion Command Center](https://github.com/gridinwork/Counter-UAS-Sensor-Fusion-Command-Center).

Публичный репозиторий описывает одну JSON-запись на строку или на UDP-датаграмму. Обязательное поле приёмника — `id`. Подтверждение компьютерного зрения — `cv: true`. Поле `confidence` в примере Command Center задано в процентах, поэтому адаптер передаёт проценты и отдельно долю `confidence_01`.

Координаты рамки остаются нормализованными относительно кадра. Широта, долгота, дальность и скорость в км/ч в событие не входят: экранная рамка без калиброванной геометрии не переводится в GPS.

## Пример

```json
{
  "id": "uav-vision-01-7",
  "sensor_id": "uav-vision-01",
  "track_id": 7,
  "time_utc": "2026-10-09T15:00:00.000000Z",
  "class": "drone",
  "confidence": 82.0,
  "confidence_01": 0.82,
  "cv": true,
  "bbox_norm": {"x": 0.1, "y": 0.2, "w": 0.05, "h": 0.08},
  "source": "rtsp://camera/stream",
  "status": "TRACKING",
  "speed_px_s": 12.5
}
```

| Поле | Смысл |
| --- | --- |
| `id` | Ключ трека для слияния в Command Center: `{sensor_id}-{track_id}` |
| `sensor_id` | Идентификатор этого видеосенсора |
| `track_id` | Идентификатор сопровождения |
| `time_utc` | Время формирования события, UTC |
| `class` | Имя класса после фильтра известных имён |
| `confidence` | Уверенность детекции, 0–100 |
| `confidence_01` | Та же уверенность, 0–1 |
| `cv` | Всегда `true` |
| `bbox_norm` | `x`, `y`, `w`, `h` от 0 до 1 в координатах кадра, начало слева сверху |
| `source` | Путь файла, индекс камеры или URL RTSP |
| `status` | `DETECTED`, `TRACKING`, `OCCLUDED`, `LOST` или `REACQUIRED` |
| `speed_px_s` | Скорость центра рамки, пиксели в секунду |

## Как отправить

Во вкладке **Экспорт / события** задаются идентификатор сенсора, адрес и порт UDP. В комплекте Command Center посты по умолчанию слушают `5001`–`5004`.

- «Передавать события» пишет JSONL в `logs/events/live.jsonl` и шлёт по одной датаграмме на трек, не чаще 5 раз в секунду на трек.
- «Сохранить JSON событий» кладёт текущий список в `output/`.
- «Отправить тестовое событие» шлёт текущие треки. Если цели нет, событие не выдумывается.

Ошибка сокета пишется в журнал окна и в `logs/app.log`, видеопоток при этом не останавливается.
