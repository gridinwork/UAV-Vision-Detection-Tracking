# Демонстрационные материалы

Все ролики и снимки этой папки — **синтетические**. На них есть надпись DEMO / SIMULATED DATA. Рамки в демо-режиме берутся из сценария, а не из обученной модели БПЛА.

| Файл | Содержание |
| --- | --- |
| `screenshots/uav_tracking.png` | Окно программы, сопровождение одного БПЛА |
| `screenshots/fpv_drone_tracking.png` | Окно программы, крупный FPV-дрон |
| `screenshots/multiple_drones.png` | Окно программы, несколько объектов |
| `screenshots/bird_vs_drone.png` | Окно программы, птица и БПЛА разными классами |
| `video/*_20s.mp4` | 20 секунд обработанного видео, 25 кадров/с |
| `source/demo_*.mp4` | Исходные синтетические ролики без рамок трекера |

Снимки сняты с живого окна PySide6. Ролики в `video/` собраны тем же контуром отрисовки, что и окно.

Кнопка «Создать демонстрационные ролики» дополнительно готовит сцены малого объекта, засветки, облаков, промышленного фона, перекрытия и птиц. Это материал для прогона своей модели, а не отчёт о точности.
